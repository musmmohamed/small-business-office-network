Designed and configured a small-business office network using Cisco Packet Tracer.
The project demonstrates practical implementation of VLAN segmentation, Layer 2 and Layer 3 switching, inter-VLAN routing, DHCP, 802.1Q trunking, LACP EtherChannel, Rapid-PVST, Port Security, network management, and network troubleshooting.
The network was designed for a small technical services company with approximately 18 employees.
